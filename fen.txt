FEN (Forsyth-Edwards Notation) is a standard notation for describing
a particular board position of chess, allowing us to restart the game
from a particular position.

A FEN record defines the position all in one text line using only ASCII characters
The FEN contains six fields, each separated by a space, where:
    1. Piece placement: 
        the piece placement data, starting with the 8th rank
        on the a-file to the h-file. Ranks are separated by a '/'
        (pawn = "P", knight = "N", bishop = "B", rook = "R", queen = "Q" and king = "K")
        When a number appears, this is the number of consecutive empty squares
    2. Active color: 
        'w'=white 
        'b'=black
    3. Castling availabliity: 
        '-' = no castle abilities
        'K' = white can castle kingside
        'Q' = white can castle queenside
        'k' = black can castle kingside
        'q' = black can castle queenside
    4. En passant target square:
        '-' = no en passant square
        'xy', x = file, y = rank
    5. Half-move clock: 
        number of halfmoves since the last capture or pawn advance
    6. Full-move number:
        number of full moves, starting from 1, incremented after black's move

For example: the starting position FEN: 
    rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1
then, after 1.e4:
    rnbqkbnr/pppppppp/8/8/4P3/8/PPPP1PPP/RNBQKBNR b KQkq e3 0 1

Notice how the en passant square becomes e3, even if there is no pawn on d6 or f6.

Using FEN, we can connect to a GUI which will display the board from a generated FEN!
